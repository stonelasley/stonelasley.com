# **Rolex Datejust 41 Ref. 126234**

# **1. General Overview**

Introduction:

Launched 2017 at Baselworld as part of Rolex’s new-generation Datejust 41 family, succeeding the 116234.

Production period: 2017 – present (as of 2025).

Key specifications

| **Feature**      | **Specification**                                                    |
| ---------------- | -------------------------------------------------------------------- |
| Case             | Oystersteel (904L / Oystersteel) with 18 ct white-gold fluted bezel  |
| Diameter         | 41 mm                                                                |
| Thickness        | ~11.8 mm                                                             |
| Water resistance | 100 m (10 ATM)                                                       |
| Movement         | Calibre 3235, in-house automatic                                     |
| Complications    | Date with instantaneous change and quick-set                         |
| Frequency        | 28,800 vph (4 Hz)                                                    |
| Power reserve    | ~70 hours                                                            |
| Crystal          | Sapphire with Cyclops magnifier                                      |
| Bracelet         | Oyster (three-link) or Jubilee (five-link), Oysterclasp / Crownclasp |
| Lume             | Chromalight (blue)                                                   |
| Certification    | Superlative Chronometer (–2 /+2 s per day)                           |

Collector significance:

First white-gold fluted-bezel Datejust using the Cal. 3235 architecture. Improved Chronergy escapement and 70-hour reserve marked a generational leap in Rolex’s core model line.

Sources: Rolex.com; Mondani Editions 2023; WatchBase.

# **7. Authentication & Restoration Checklist**

Originality checks

- Serial and model engraved between lugs (invisible unless bracelet removed).
- Rehaut engraving perfectly radial.
- Dial lume uniform blue under UV.
- Rotor stamped “Rolex 3235” with Geneva waves, not perlage.
- Bracelet reference + clasp code correspond to case year.

Red flags

- Service dials lacking coronet at 6 o’clock.
- Aftermarket bezels with incorrect gold alloy.
- Over-polished lugs losing chamfer lines.

Restoration guidance

- Do not re-cut flutes; replace bezel if damaged.
- Preserve factory brushing; light case refinishing only.
- Replace gaskets + crown seals every 5 years.
- Pressure-test after service (10 bar).
- Document service with serial and date.

# **8. Summary**

The Rolex Datejust 41 Ref. 126234 unites Rolex’s classic white-gold fluted bezel aesthetic with the advanced Cal. 3235 architecture. Mechanically robust, visually conservative, it represents the modern standard for the Datejust line. Its collectability stems from first-generation 3235 adoption and balanced proportions returning closer to vintage Datejust 36 ratios. Current market value (2025) remains strong, particularly for Wimbledon and blue-sunburst dials.
